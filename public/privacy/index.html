送出前，先知道資料會去哪裡。

這份說明對應此開源版 VerifyFirst 的預設程式行為。請勿輸入密碼、OTP、完整卡號或證件號碼、助記詞、錢包私鑰或 API 金鑰。

自架者是自己部署環境的資料處理者，可更換供應商、關閉整合或改變保留方式；上線前應根據實際設定發布自己的法律文件。這份開源說明不取代部署者的法律義務。

To C 反詐輸入

送出的文字、OCR 擷取文字或 URL 會到 VerifyFirst API、Gemini，並依部署者啟用的設定送到公開查核服務，例如 Safe Browsing、VirusTotal、Cofacts、RDAP 與 DNS。

截圖與檔案

圖片 OCR 在瀏覽器執行；第一次使用時，Tesseract 可能自預設 CDN 下載 worker、core 與語言資料。圖片本身不送到 VerifyFirst API，但擷取後文字會成為查核輸入。To B 文件只在本機計算 SHA-256，下載包不含內容。

暫存與限流

分析結果可在伺服器單一暖實例的有界記憶體中保留最長 72 小時。IP 只以雜湊後的暖實例限流鍵使用。專案預設不使用 Blob 或共用持久快取。

選用處理

Vercel Analytics 預設關閉。Google Sheets webhook 若由部署者啟用，只傳送不含使用者輸入與證據原文的統計欄位。URL 內容觀測預設關閉，需由伺服器明確啟用。

企業實驗室

vLEI 的原始 CESR 在瀏覽器記憶體預檢；GLEIF 查詢傳送 20 字元 LEI。x402 LIVE 會將清除 URL 帳密、query 與 fragment 後的 endpoint 識別字、Payment-Required 及企業政策送至 VerifyFirst API，再交給 IFF 比對。VerifyFirst 不接收錢包私鑰、不簽名、不付款。Simulation 不連線 IFF。

安全與選擇

  • 若不希望內容進入第三方服務，請勿送出 To C 分析；可使用不連線的企業 simulation 與本機雜湊功能。
  • 專案沒有使用者帳號，也沒有帳號資料庫可供刪除。暖實例資料會在重啟或最長保留時間後失效。
  • 敏感的安全或隱私問題請使用 GitHub 的 private vulnerability reporting；公開 issue 請勿夾帶個人資料。
